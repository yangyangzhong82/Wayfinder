# Wayfinder

LeviLamina **26.51.5 客户端**小地图模组。提供主世界地表／洞穴、下界和末地小地图、全屏地图、分层探索历史、路标导航、死亡点记录和游戏内设置。

## 操作

| 按键 | 功能 |
| --- | --- |
| M | 打开/关闭全屏地图 |
| N | 显示/隐藏小地图 |
| + / -（未打开全屏时） | 放大/缩小小地图，自动保存；可在设置中改键 |
| Esc | 取消字段输入／退出菜单／关闭全屏地图 |
| 左键拖动、按住方向键或 WASD | 连续平移全屏地图 |
| 滚轮、加减键 | 缩放地图，鼠标在地图内时以指针为中心 |
| Home | 恢复跟随玩家 |
| F | 显示当前地图层磁盘历史与当前采样中的全部已知区域，受缩放上限限制 |
| 全屏顶部 + Here | 在玩家当前位置添加路标 |
| 地图右键 | 打开位置菜单，选择传送或在此添加路标 |
| 左键单击地图路标 | 打开该路标编辑器；拖动超过 3 个 GUI 单位仍为平移 |
| Shift + 左键单击路标 | 直接设为导航目标 |
| 全屏顶部 Waypoints / Settings | 路标列表／游戏内设置 |
| 全屏顶部 坐标定位 / Locate | 输入 X/Z 浏览指定位置，或在该位置建点 |
| 全屏顶部 回到玩家 / Follow | 回到玩家位置并恢复跟随，保留缩放比例 |

界面默认跟随 Minecraft 当前语言。游戏选择简体中文时自动显示中文；可在模组设置中切换“跟随游戏／简体中文／English”。目前内置简体中文和英文，其他游戏语言回退英文。切换语言不改写自定义路标名称。

## 洞穴、下界与末地

- 默认使用“自动”地形模式：主世界根据可设置的玩家 Y 高度自动切换洞穴／地表，下界按玩家高度显示内部地形，末地显示岛屿表面。小地图和全屏地图使用同一图层。
- 洞穴按世界 Y 坐标每 8 格分层，标题显示当前层的参考高度；上下移动跨层后自动更新。在层中心上下 4 格内寻找最近的空间，再向下采样洞底，显示墙体、水域和岩浆，避免把下界基岩顶层当成内部地图。多个洞穴若挤在同一高度层内，显示离层中心最近的空间。
- 主世界自动模式在玩家 Y 小于或等于“洞穴切换高度”时进入洞穴显示，默认 **Y=48**；上升至阈值上方 4 格时返回地表（默认 Y≥52），避免在边界附近跳跃时反复切换。这里使用绝对世界高度，不受头顶建筑或树叶影响。
- 在 **M → 设置 → 地图叠加 → 地形模式** 点击切换“自动／地表／洞穴”。也可配置 `terrainMode` 为 `auto`、`surface` 或 `cave`；手动洞穴模式仍跟随玩家高度，可用于任意维度。
- 同页的 **洞穴切换高度** 可通过 − / + 按 1 格调整，范围 -64～320，修改后自动保存并在下一次客户端 Tick 生效；配置字段为 `caveSwitchY`。高度阈值仅影响主世界的自动模式，手动模式及下界／末地默认策略不变。
- 地表、各洞穴高度层和各维度分别保存历史；切层时未探索的部分显示棋盘格，回到原层可读取其历史。F 键显示全部区域、坐标建点和右键落点高度都使用当前层，不把洞穴落点替换成头顶地表。
- 深灰色为洞穴实心墙体，暗紫黑色为已确认的虚空；两者不可作为地图传送落点。尚未收到的数据继续显示棋盘格，不会主动加载远处区块。单列扫描有预算上限，极深竖井或数据不完整时可能暂时显示未知。

## 地图信息与坐标定位

- 地图显示东南西北、随缩放变化的比例尺，以及“跟随玩家／自由浏览”状态。比例尺以方块为单位，按实际地图贴图到 GUI 的比例计算。
- 设置中可分别开关比例尺、方向标识、区块边界和玩家群系。区块边界为实际 16×16 格边界，缩小时线间距不足 6 个 GUI 单位会隐藏，避免遮住地形。
- 群系显示玩家当前位置（包含玩家高度）的群系，每 0.5 秒更新，仅查询已收到的区块；拖动地图不改变其含义。已知原版群系提供中英文名称，未知或自定义群系保留标识符，未就绪时显示“未知”。
- “坐标定位”使用当前维度的 X/Z 整数坐标，支持负数；“定位到此坐标”移动地图视图，“在此坐标建点”进入路标编辑器。不会传送玩家、探测或加载远处区块；没有历史的地方仍显示未知地形。
- “回到玩家”按钮与 Home 均可恢复跟随。自由浏览时不再将中心强制吸附到纹理像素，定位到的方块会精确居中。

### 右键传送与地形高差

- 按 M 打开地图，在目的地右键，再点击“传送”。菜单固定右键选中的坐标，移动鼠标选择按钮不会改变目的地；保留“在此坐标建点”，Esc 或点击菜单外关闭。
- 传送通过当前玩家的原版 `/tp` 命令请求执行，需要开启作弊并具备命令权限；最终结果由游戏／服务器判定，发送后关闭地图以显示原版反馈。不会直接修改客户端位置。
- 落点为选中方块的 X/Z 中心、当前地图层地形上方一格。命令使用 `checkForBlocks=false`，避免强制障碍检查阻止向未加载区域传送；不能根据客户端已加载状态判断服务端是否已加载。附近已加载区块在点击传送时重新采样当前层，包含水面和树叶；远处已探索区域从同层历史文件异步读取高度。历史高度可能过时，关闭障碍检查不保证落点无方块或其他危险。
- 尚未探索或无法取得地形高度的位置禁用传送；读取历史时显示进度提示，不使用玩家当前 Y 猜测落点，也不主动加载服务器未发送的地形。
- 小地图和全屏地图使用西北向坡面光照，高差越大，明暗反差越明显；叠加每 8 格高度带的上侧轮廓和轻量海拔明暗，平坦高台在缩小时也能区分。水体按深度连续变暗，便于分辨浅滩与深水。已有历史无需重采样即可应用新着色。

## 路标、导航与死亡点

- 路标支持名称（最多 32 个字符）、X/Y/Z、8 种颜色和 4 种图标。点击字段编辑，Enter 完成，Ctrl+A 全选，Ctrl+V 粘贴；中文名称可粘贴输入，暂未接入中文输入法候选窗。未知地形的 Y 留空，不用玩家高度冒充地形高度。
- 地图上的图钉、房屋、传送门和骷髅使用缓存小图标图集；8 色、目标边框和 16 方向边缘箭头一起预生成，每个路标只提交一次贴图绘制，同一轮统一刷新。图集首次使用时上传，资源包重载后重建，不随地图刷新或路标编辑反复上传。
- 点击列表中的路标进入编辑；Save 保存，Save + Navigate 保存并设为目标。Delete 需要再次点击确认，Back / Cancel 放弃未保存编辑。每个世界最多 512 个永久路标。
- 路标列表支持名称搜索（英文不区分大小写，中文可粘贴）、维度筛选、最新/距离/名称排序，以及自定义分组筛选；点击筛选项循环切换，“清除筛选”恢复全部。距离排序优先当前维度，其他维度不比较距离。
- 编辑器可填写一个分组标签（最多 32 字符，留空为未分组），保存后随路标持久化；旧版 JSON 自动视为未分组。地图图标可直接点击编辑，Shift+点击直接导航；绘制与命中共用图标坐标。密集标签优先为目标安排位置，再尝试上下左右避让，放不下时隐藏标签，图标保留真实地理位置；完全重叠的路标仍可通过列表逐一操作。
- 导航显示水平距离与八方向方位；同维度目标超出地图时显示边缘箭头，接近 2 格以内显示 Arrived。跨维度仅提示目标所属维度，不计算跨维度距离或自动换算下界坐标。Stop navigation 停止导航。
- 客户端 Tick 检查本地玩家存活到死亡的状态转换，记录位置、维度、UTC 时间。保留最近 5 次死亡；进入世界时已在死亡界面不会补造记录。编辑死亡点后选择 Convert to permanent waypoint，再保存，可长期保留。
- 路标列表包含各维度，地图只绘制当前维度标记。菜单内容较多时使用 Previous / Next、滚轮或 PageUp / PageDown 翻页。编辑菜单会独占按键，避免输入名字时触发地图快捷键。
- 路标与目标保存在数据目录 `waypoints/<世界哈希>.json`，沿用地图的世界/profile 隔离规则。每次保存采用临时文件原子替换；损坏文件保留，新记录写入 recovery 文件。死亡点保存失败会在当前会话重试，界面编辑保存失败会保留编辑内容。

## 附近实体

- 小地图和全屏地图均显示已同步到客户端的附近生物和玩家：默认以头像显示 74 种原版生物，其他玩家为青色标记并显示名字；未适配生物及贴图未就绪时使用橙色标记。本地玩家继续使用原有朝向标记。掉落物、经验球、投射物、船、矿车、盔甲架等非生物和已死亡的生物不显示，也不占用标记名额或计数。
- 打开全屏地图 → 设置 → 叠加 → 实体显示／类型筛选，可开关实体显示、调整半径、选择仅玩家或逐类勾选；支持按中文名称和实体 ID 搜索。附近发现的自定义实体会加入列表。
- 同一页面的“显示生物头像”可切换头像／圆点，默认开启并自动保存。头像使用当前资源包的生物贴图，按原版头部位置裁切、组合鼻子和耳朵；不会打包游戏贴图或联网下载。当前按类型显示固定代表外观，不读取玩家皮肤、生物颜色变种和幼年外观；改变模型 UV 布局的资源包可能不匹配。
- “小地图实体图标比例”默认 75%，每次调整 5%，范围 25%～200%，同时缩放头像和圆点；全屏地图仍保持原始图标大小，玩家名字保持可读字号。
- “低处生物透明度”默认 65%，可在 0%～90% 间调整，越高越淡；0% 可关闭淡化。“低处判定高差”默认 4 格，可调 1～64 格：比玩家至少低这么多的生物和其他玩家会淡化，头像、圆点、数量与名字同步生效。这是相对玩家高度判断，不检测头顶是否有洞穴顶；走到同一层会恢复正常，两种地图均适用。
- 拥挤位置的同种生物合并成“头像＋数量”，不同种类、地表／低处分组分别保留；其他玩家不会合并。缩放地图靠近后，生物会自然拆分。头像适度避让，细线和小点指向真实位置，避免多张脸堆叠或遮住自己；玩家名字也会寻找附近空位。头像、圆点、数量和名字均不绘制黑色背景，每个头像独立提交贴图，避免混合种类在同一图像批次中串图。
- 小地图外层面板、比例尺和导航文字不绘制黑色底板，背景完全透明；地形、图标和文字仍正常显示，地形透明度继续由小地图透明度设置控制。
- 默认显示全部类型，半径为 64 格，可调整为 16～256 格；洞穴和下界分层地图还限制与玩家高度差不超过 16 格。客户端未加载的实体不会显示，扩大半径不会请求服务器加载实体。
- 选择“仅选中的类型”后只显示勾选项，清空选择表示全部隐藏；“显示全部类型”恢复全部。设置自动保存。玩家名字不写入地图历史。
- 实体设置底部显示“已加载／附近／待显示”数量：依次为客户端快照中的存活生物和玩家、同维度半径内生物和玩家、通过开关／类型／高度筛选的生物和玩家；均不含自己及非生物。“待显示”是合并前的生物数量，不是头像数量；实体仍可能因地图缩放或平移位于屏幕外。

## 游戏内设置

全屏地图顶部使用紧凑工具栏，窄窗口自动换为两行。点击“设置 / Settings”打开居中面板，按“外观 / 地图叠加 / 常规”分类：调整小地图位置、大小、缩放、透明度，开关坐标、路标、目标导航、死亡记录、水面/树叶及信息叠加层，并修改语言和地图/缩放快捷键。开关独立显示状态，数值通过 − / + 调整；位置百分比按从左到右、从上到下计算。小窗口保留分页并显示页码，不能翻页时按钮禁用。点击后立即生效并写入 `config.json`；水面和树叶更改会重新巡检附近已加载区块，远处历史待再次采样后更新。

常规页提供省资源／均衡／精细性能预设，调整采样半径、每 Tick 列数和软时间预算、贴图分辨率与刷新间隔；手动修改这些参数后显示“自定义”。均衡使用原有默认值。恢复默认需要再次点击确认，仅恢复界面与采样偏好，保留历史、路标、世界档案、缓存容量和自动保存周期。其余性能与世界档案参数仍通过配置文件调整。

改键时点击对应按钮，再按字母、数字或 F1–F12；缩放键还支持主键盘或小键盘加减键。Esc 取消；W/A/S/D/F 留给平移和显示全部区域，四个地图/缩放快捷键不能相同。默认主键盘 + / - 在小地图可见且未打开全屏时缩放小地图；全屏仍沿用原有滚轮与加减键缩放。修改不会注册到原版游戏键位菜单，请避开自己使用的游戏快捷键。旧配置若已将加减键分配给开关地图，新缩放键会选择空闲默认键。

北方朝上；白点为玩家，黄线指示朝向。棋盘格代表尚未收到/采样的地形，不会自动探测服务器未发送的区域。全屏期间暂停游戏操作，**不会暂停世界或服务器**。聊天、背包等界面不响应地图快捷键。当前仅支持键鼠与主客户端视图。

坐标按所在方块向下取整（包含负坐标）；全屏地图额外显示鼠标所指位置的 X/Z。关闭再打开全屏地图会保留本次运行的缩放比例。长按平移速度按时间计算，斜向速度归一化。

小地图的显示中心精确跟随玩家，采样贴图四周额外预留 8 个像素，通过每帧更新 UV 实现亚像素滚动。贴图合成仍按刷新间隔节流；玩家、路标、区块网格和比例尺使用相同的可见范围。快速移动超出预留边缘时用当前缓存立即补图，避免边缘拉伸。

缩小时按覆盖面积汇总颜色与已探索状态，使用 1/2/4/8/16 格分级聚合；远景使用区块概要，不再仅取像素中心的一个方块。跨区块移动会保留重叠范围的扫描进度与待更新任务，优先巡检未采完的区块。

全屏地图只使用系统原生鼠标光标，不额外绘制大箭头。地图打开期间阻止游戏重新抓取鼠标，鼠标可以移出窗口；移出客户区、失焦或松开左键都会结束拖动，重新进入不会接着拖。点击、拖动与滚轮缩放统一使用系统光标的客户区坐标，读取失败时不跳回中心。关闭地图恢复原有鼠标抓取，切换窗口或打开其他界面会关闭地图。

## 构建与安装

```powershell
xmake f -y -p windows -a x64 -m release --target_type=client
xmake -y
```

将构建生成的整个 `bin/Wayfinder/` 放入匹配 LL 26.51.5 的游戏客户端 `mods` 目录。不要加载到服务端，不要混用不同版本的 MC/LL 运行库。

首次加载在 LL 提供的模组配置目录生成 `config.json`。

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| fullMapKey / toggleMinimapKey | 77 / 78 | Windows 虚拟键码，对应 M/N；游戏内改键立即生效，手动改文件后重启 |
| minimapZoomInKey / minimapZoomOutKey | 187 / 189 | 主键盘 + / -；游戏内可改，不能与地图开关按键重复 |
| sampleRadiusChunks | 8 | 玩家周围巡检半径，不会主动加载区块；优先覆盖小地图可见范围 +1 区块，最终最多 16 区块 |
| columnsPerTick | 1024 | 每 Tick 采样列数上限 |
| samplingBudgetMicros | 1500 | 采样循环软预算，单次引擎调用可能超出预算 |
| minimapPixels / fullscreenPixels | 128 / 384 | 小地图分辨率、全屏贴图宽度 |
| minimapSize | 112 | 小地图边长，单位为 GUI 单位 |
| minimapOpacity | 0.92 | 小地图地形贴图不透明度，0.2–1.0；外层面板背景完全透明，标记保持清晰 |
| minimapPositionX / minimapPositionY | 1.0 / 0.0 | 小地图在可用屏幕区域中的位置，0–1，默认右上 |
| showCoordinates / showWaypoints / showNavigation | true | 显示坐标／路标／目标导航 |
| recordDeaths | true | 记录之后发生的死亡，关闭不删除已有记录 |
| language | auto | 跟随游戏语言；可设为 zh_CN 或 en_US 强制使用内置语言 |
| showScale / showCompass / showBiome | true | 比例尺／方向标识／玩家当前位置群系 |
| showEntities | true | 显示附近实体；玩家附带名字 |
| entityPortraits | true | 显示已适配生物的头像；false 使用原有圆点 |
| minimapEntityScale | 0.75 | 小地图实体图标比例，0.25～2.0；全屏图标大小不变 |
| undergroundEntityOpacity | 0.35 | 低处实体不透明度，0.1～1.0；界面显示的透明度为 1 减此值 |
| entityDepthThreshold | 4 | 低于玩家至少多少格时淡化，1～64 格 |
| entityRadius | 64 | 实体显示半径，16～256 格；受客户端已加载范围限制 |
| entityFilterEnabled | false | false 显示全部类型；true 仅显示 entityTypes 中的类型 |
| entityTypes | [] | 类型白名单，例如 ["minecraft:player", "minecraft:zombie"]；启用筛选且为空时全部隐藏 |
| showChunkBorders | false | 显示 16×16 格区块边界；缩得很远时自动隐藏 |
| minimapBlocksPerPixel | 2.0 | 小地图每贴图像素覆盖的方块数 |
| refreshMilliseconds | 100 | 后台地图合成请求间隔；历史读取期间显示上一张地图，玩家标记每帧绘制 |
| autosaveSeconds | 30 | 后台自动保存间隔；退出世界和禁用也保存 |
| maxCachedChunks | 8192 | 前台采样缓存及后台历史详情缓存各自的区块上限；不限制磁盘历史 |
| includeWater / includeLeaves | true / true | 地表高度查询包含水和树叶 |
| terrainMode | auto | 自动切换地形模式；surface 强制地表，cave 按玩家高度显示洞穴 |
| caveSwitchY | 48 | 主世界自动模式：Y≤此值进入洞穴，上升至此值+4返回地表；可设 -64～320 |
| cacheProfile | 空字符串 | 默认使用 LevelId；可指定世界唯一名称覆盖自动识别，或在缺少 LevelId 时复用跨会话历史 |

快捷键使用 LL KeyInputEvent，通过模组设置界面或配置改键，不注册原版游戏键位设置。设置读入时限制到合理范围；语法错误会记录日志并拒绝启用。N 切换小地图显隐也会保存。

## 世界隔离与存储

- 有效 LevelId 优先作为存档标识，即使本地世界开启多人游戏也不会改用临时会话文件；只有没有 LevelId 时才使用独立会话记录。存档信息不足不会阻止小地图和 M 键启动，也不再等待网络连接信息就绪。
- 没有 LevelId 的独立会话每次进入生成不同记录，这种情况下默认不跨重进读取历史或路标。日志中的 `Wayfinder session:` 会显示多人状态、LevelId 与最终标识；多人状态仅用于诊断，不参与存档键的选择。
- 自动识别无法区分世界时（如服务器缺少或复用 LevelId），填写唯一 `cacheProfile`（例如 `friends-survival-2026`）。换服务器/存档时必须换名称；相同 profile 会主动复用历史。已有 `local:<LevelId>` 文件保持兼容。
- 新历史存放在 LL 模组数据目录的 `maps/<世界哈希>.wfmap.tiles/`，按维度、洞穴高度层和区块分别存储。地表沿用 `<维度>_<区块X>_<区块Z>.wfmap`，洞穴增加 `_c<层索引>` 后缀。新文件使用 v4 格式，兼容读取 v1/v2/v3 地表历史；旧 `*.wfmap` 快照首次打开时自动迁移并保留原文件。实际世界路径会打印到日志。
- 文件带版本、身份、大小验证，单区块后台保存采用临时文件原子替换；保存采样访问顺序，重新进入后保留淘汰优先级。单个坏区块文件重命名为同目录的 `*.wfmap.corrupt-*`，保留原始字节并继续加载健康区块；重新探索可重建该区块。隔离失败时保留原文件并阻止覆盖；世界身份文件或整个目录无法读取时才使用独立 recovery 目录。
- 历史扫描、旧文件迁移与近期区块预加载均在后台进行，界面显示扫描数量或读取进度。期间小地图和 M 键可用、继续采样当前区域；载入结果只补齐未知格，不覆盖期间的新采样或丢弃待保存数据。正常退出/禁用会等待后台加载和保存结束。坏块数量、恢复档案及 I/O 错误会在地图信息栏提示，具体路径见日志。
- **内存淘汰不会删除磁盘历史。**浏览旧区域时按需加载细节，远景使用内存中的区块概要；重新采到的部分区块只合并有效格子，不覆盖未就绪的历史。磁盘占用和概要索引随探索量增长，目前不自动清理历史。
- 自动保存周期内的最新修改仍可能留在内存；后台缓存淘汰会提前落盘，正常退出世界和禁用会等待保存完成。磁盘错误会记录日志并重试，待保存队列积压时暂停采样。每个区块独立原子替换，不保证所有区块在崩溃时同时完成保存。
- 路标在点击保存时立即写入，进入世界时日志会输出路标文件路径、存档标识及载入数量。旧版误用 `session:` 标识留下的文件会保留，但其中没有可验证的本地世界归属，因此不会自动合并到当前世界。

## 模块

- `src/wayfinder/MapCore.h`：坐标、缓存、雾区、高度阴影和视图变换。
- `MapLayer.h` / `TerrainColumn.h`：维度与高度层标识、自动模式选择、洞底／液面采样及墙体／虚空分类。
- `TerrainSampler` / `SampleSchedule.h`：客户端 Tick 分批读取区块，移动保留重叠队列，未就绪数据不覆盖已有样本。
- `MapRenderer`：Image → ImageBuffer → TextureGroup → TexturePtr → drawImage。
- `MarkerAtlas`：16×16 小图标、配色、目标描边及方向箭头的运行时图集；无需额外资源包。
- `MapMarkers`：共享图标绘制/命中坐标、目标优先级及密集标签避让。
- `EntityRadar.h` / `WayfinderEntities.cpp`：类型筛选、附近实体快照、玩家名字和地图投影；每 250 ms 读取一次客户端实体，最多保留 512 个标记，优先玩家及较近实体。
- `EntityPortraits.h` / `PortraitPixels.h`：74 种生物的头部 UV 与部件布局、发光／染色掩码转换和有界头像纹理副本；原版贴图由客户端资源系统读取。
- `Wayfinder.cpp`：事件订阅、回调互斥与异常保护、启停生命周期。
- `WayfinderSession.cpp` / `WayfinderHistory.cpp`：世界会话、玩家快照、采样、路标持久化及串行后台存档/合成任务。
- `WayfinderInput.cpp` / `WayfinderMenu.cpp`：键鼠输入、鼠标接管与恢复、菜单操作及文字输入。
- `WayfinderView.h/.cpp`：独立于引擎的布局、跟随、缩放、拖动与全历史范围计算。
- `WayfinderRendering.cpp`：贴图刷新节流、后台合成请求、绘制调度和渲染失败恢复。
- `WayfinderInternal.h`：私有组件组成与跨模块接口；会话、输入、菜单和渲染各自持有状态。
- `MapStorage` / `MapArchive`：版本兼容、区块历史、有限详情缓存与后台地图合成；工作线程只处理自有数据，不访问 MC 对象。
- `Navigation`：路标数据、死亡点保留、目标投影与原子保存。
- `MapMenu` / `MapUi` / `Settings`：分页菜单、字段编辑、统一绘制与命中区域、即时设置与配置读写。
- `Locale` / `Translations.inc`：集中式中英文词条与游戏语言选择，未支持语言回退英文；新增词条需同时提供英文、简体中文。日志保留开发诊断信息，用户界面显示本地化提示。
- `MapOverlays.h`：比例尺、区块网格坐标和定位视图计算。

API 核对与待实测事项见 `src/wayfinder/API_NOTES.md`。

独立回归测试（无需启动游戏，不打包进模组）：

```powershell
xmake build -y WayfinderFeatureTests
xmake run WayfinderFeatureTests
xmake build -y WayfinderNavigationTests
xmake run WayfinderNavigationTests
xmake build -y WayfinderMarkerTests
xmake run WayfinderMarkerTests
xmake build -y WayfinderTerrainTests
xmake run WayfinderTerrainTests
xmake build -y WayfinderEntityTests
xmake run WayfinderEntityTests
```

**编译通过不等于完成游戏实测。**需验证 HUD/材质显示、地表高度、GUI 比例、滚轮方向、资源包重载、按住移动/攻击键打开地图、切换维度、退出重进和禁用。

本版不包含材质顶面采样、地图旋转或触屏/手柄支持。洞穴地图是高度分层俯视图，不进行三维连通性分析。
